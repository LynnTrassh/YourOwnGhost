## 自由描述实体化与首屏/入梦加载（替代上一节严格输入限制）

按用户修正，开放输入不再因抽象、声音或多主体描述拒绝。正式 VibeToken 提示优先提取一个代表性具体实体；没有具体实体则给出语义相近的实体象征，并保存原文与symbolic标记。实体化后只把外观传给模型，剧本继续掌控行为/出现位置。防御性归一化保留具体主体，未给出合格实体时按语义关键词映射；完全未知主题用承载原文的纸条作为明确的象征，不声称完整实现抽象体验。旧的不兼容解释会重新解释，兼容已生成实体不因版本变化强制重收费。

抽象映射确认页显示“建议填写具体物件”及映射结果，提供返回修改/继续入梦；后者确认后准备完成自动进入。理解/准备页始终可直接入梦，准备错误自动进入预设。地图worker支持取消且单次最多15秒，预设入口规划失败使用合法基础地图。仍无法保证硬件/WebGL故障时可玩，生成质量与云端可用性也不承诺百分百成功。

标题页改为bootstrap轻量UI（生产JS入口约32KB，非总下载大小），点击准备/进入时才导入3D运行时；标题不再创建或加载完整场景。createWorld保留同步兼容接口，并新增同一构建器的分段异步入口。入梦显示准备提示，主要美术等待最多5秒、纹理分段预上传、异步编译材质，再交出控制；迟到资源仍保留原有fallback机制。未改chen美术资产和模块。没有完成全设备帧耗时基准，不承诺零卡顿。
