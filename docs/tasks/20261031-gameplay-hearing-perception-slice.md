# S06／TH02：听声感知切片

- 责任方：玩法／程序方
- 状态：可选运行灰盒接入；S06 与 TH02 整卡未验收
- 修改范围：`src/threat-hearing.js`、`src/player-noise.js`、`src/threat.js`、`src/planning/generate.js`、`src/planning/dream.js`、`src/main.js`、`src/world.js`、相关测试及 S06／TH02 卡
- 目标：将真实世界声源事件和听声者的最后声源记忆独立出来，避免以玩家实时坐标替代听觉。

## 接口与验证

`createWorldNoise` 仅接受带事件 ID、合法世界位置的脚步、门、撞击或碎裂事件；旁白不能成为世界噪声。`audibleWorldNoise` 基于房间图的门数和世界距离作初筛；调用方可传入当前关闭的门 ID，让关门边的传播成本增加。`stepHearingMemory` 只在接受新事件时更新最后声源；停步后转入限时搜索，暂停冻结；重复事件不重触发。定向测试覆盖非法事件、断开连接、距离与门数上限、开关门传播差异、重复事件、玩家换位置后不凭空更新目标、暂停和搜索超时。

`stepHearingInvestigator` 在现有导航图上朝最后声源寻路，逐步移动并用碰撞约束；新事件才更新目标，抵达后搜索。`resetHearingInvestigator` 清除目标、路径及搜索状态并回到指定出生点。定向测试以生成地图的真实卧室门验证跨房抵达、暂停冻结和复位。此接口不读玩家实时位置，也不修改 TH01。

`createPlayerNoiseTracker` 依据碰撞后的实际位移发出脚步事件；堵墙按键、暂停、床上未起身及传送不产生脚步。运行入口把事件交给威胁逻辑，声音输出仍保持禁用。显式 URL 参数 `?threat=hearing` 才让第二层改用听声者灰盒；默认仍是凝视型。听声者第一次听到脚步后进行无伤害示范，移动及字幕窗口结束才开放危险；暂停冻结、普通死亡重置目标并保留示范消费。代理模型暂用现有简模，不能代表听声者的正式外观。
