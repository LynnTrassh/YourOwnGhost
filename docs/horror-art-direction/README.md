## 如何放进项目

将整个 `docs/horror-art-direction/` 放到当前游戏项目根目录的 `docs/` 下。如果已有同名目录，请先人工比较并保留旧版文件；不要覆盖开发中的同名研究记录。

## 给 Codex 的第一轮任务（直接复制）

> 你现在担任《心里有鬼 / YOUR OWN GHOST》的程序化恐怖美术导演。请先依次阅读 `docs/horror-art-direction/README.md`、`CODEX_HORROR_ROOM_DIRECTOR_v2.md`、`ROOM_RECIPES_v2.md`、`RESEARCH_LINKS_v2.md`、`ROOM_QA_v2.md` 及 `data/room_recipe_candidates_v2.json`。  
> 先审计现有游戏的房间生成器、预设与资产库、事件权限、地图种子、真实玩家相机、导航与碰撞，再做**有来源的联网参考研究**。对现有的“墙纸走廊、旧档案室/空客厅、供奉室”优先提出：**全是手的走廊、堆满东西的房间、血色房间**三类完整构图，每类至少 2 套原创方案；明确主导规律、主物件簇、疏密、光源、玩家入门/走近/回望视角、资产复用与可行性。不要把“一个房间一个异常物件”的旧限制套用到 L4–L5 噩梦房。  
> 先输出可核查的研究卡、构图卡和接入计划；此阶段**不允许修改地图拓扑、事件、玩家控制、已有锁定资产，不批量生成模型或覆盖原图**。如果我授权原型实现，先只做一间安全可回滚的 A/B 预览，并按 QA 同种子实测后再讨论批量接入。

## 核心辨别

- **心理房**：少数“摆错了”的东西（如《8号出口》式微差）。
- **噩梦房**：同一种超现实规则**占领整间房**（例如墙上长满手、物件把空间堆没、室内被血红照明吞没）。
- 所有类型：**空间与物件要像人设计的，不是随机资产堆**；出口、交互、性能与种子必须稳定。
