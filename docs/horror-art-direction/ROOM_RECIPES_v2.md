# 程序化恐怖房间组合手册｜ROOM RECIPES v2.0

> 本手册从美术指导转换为布景层面的“可生成”指令。`intensity` 是美术强度（0–5），**不是现有游戏字段**。物件 tag、尺寸示例只为设计思路；任何脚本应先映射真实项目资产。

## 0. 生成器每次必须提交的五件事

1. 房间的**原本功能**和**为什么现在不合理**。
2. 一个**主导噩梦规律**（颜色、重复、增殖、遮挡、活体化、空缺、仪式）。
3. **主视觉轮廓 + 两到五组有关系的物件簇 + 一处可呼吸的空域**。
4. **从玩家入口自然视角**观察时的前景、中景、远景；以及玩家自然移动后的第二发现。
5. **真正可通行的出口**、物件碰撞、性能与 seed 复现证明。

> **重要变化：** 对强度 4–5 的房间，不限制出现几件恐怖物体。可以布满手、布满玩具、堆满档案、整个房间深红。限制的是**一个房间只能有一个清晰的统治规律**，而不是实体数量。

## 1. HERO N01｜手之走廊 Hall of Hands

**目标**：第一眼是一个普通而狭窄的通道，走进去才发现建筑表面存在越来越密集的手。玩家不是遇见一个怪物，而是感觉**整栋建筑在触摸自己**。

### 1.1 构图剖面

```text
玩家入场                                       出口
  ↓                                             ↓
[普通旧墙] → [零散手形] → [两侧成群伸向中轴] → [密集手之门洞] → [留出可辨出口]
 稀疏       单侧    叠层高低错位/向前抓取      一次视觉高潮        低密引路
```

- **建筑锚点**：窄长廊、每隔一段出现门框/壁灯/管线。灯距是尺度参照；正常结构比手群更重要。
- **主轮廓**：中段与远端形成“手指之林 / 手腕拱门”的剪影，绝不是每平方米均匀塞手。
- **位置规则**：墙角先小群出现，中段沿墙两侧逐渐密集；个别从门缝、柜底、上方管线后伸出。方向大体朝向玩家行进轴；少数手背向玩家或缩回形成节奏。
- **形体层次**：3 类原型（短手/长臂/不完整的手形装饰），每类少量变体；大小/朝向要受约束，避免一大批同模重复“游戏关卡感”。
- **光色**：旧墙暗灰绿，手群偏灰白或陈旧木偶感；灯光形成连续投影，关键区可有低亮暗红。不必整体全红。
- **第二发现**：回头时玩家发现此前空白的墙段也呈现手形轮廓（如果已有状态机制才做变化；否则用从入口看不到的反面簇实现）。
- **音频建议**：布料/墙体摩擦与非常轻的指节敲击；非要求自动加入新音效系统。

**生成顺序**：先安全通道 → 沿墙定义可摆放带 → 放大中型簇 → 填背景手 → 用前景门框遮挡一部分 → 镜头验证 → 清理无意义的孤立手。

**可控变体**：`static_mannequin` 静态人偶手 / `organic_imprint` 墙中手印凹凸 / `shadow_only` 墙面影子版本 / `gallery_of_gloves` 长手套版本。不要强制所有版本都需要带骨骼动画。

**最低成本版**：6–12 个复用静态原型实例 + 贴花影子 + 局部遮挡，先证明视觉结果。**动态手的行为**必须独立经事件系统批准。

**失败示例**：全部手水平伸出、方向随机且像挂钩；密度平均；从入口看不出走廊尽头；每只手都有独立碰撞体；复刻现成游戏可识别的手臂资产。

参考研究：`Little Nightmares II`（病院/Patients 的空间与肢体感，官方页面见 RESEARCH）+ `Scorn` 的建筑有机化；**本配方是原创组合，不是对这些游戏某个房间的复制指令**。

## 2. HERO N02｜堆积之屋 Hoarder Chamber / Object Avalanche

**目标**：不像普通仓库那样“东西很多”，而像一个人把记忆、生活与恐惧挤压到同一间房。先建立“谁在这里住过”，再扭曲为仓储、藏匿或仪式。

### 2.1 布置骨架

| 视觉层 | 主要物件 | 布局/叙事规则 |
|---|---|---|
| 大件 | 柜子、床、餐桌、沙发、立柜 | 三个物件应共同暗示原用途；选一件被完全淹没的核心大件 |
| 中件 | 纸箱、书叠、电视机、废弃玩具、装订档案 | 按**同一类别/年代/归属**形成成组堆体，主堆一高一低 |
| 小件 | 杯、钥匙、药瓶、照片、标签、日历、塑料花 | 少量剧情信息；每类小件不能无意义刷几十个 |
| 空隙 | S 形走道、眼平空洞、门口底部缝隙 | 让玩家能穿过，且能从堆积之间看见一个目标 |
| 异常 | 一百张同一人的照片、所有箱贴同一日期、每只鞋朝同方向 | 选择**一个**有意义的规律，用数量夸张，而不是叠加五种谜语 |

### 2.2 相机可见的形体关系

- 从入口能看到**最高堆体**遮住 1/3–1/2 的远墙视觉范围（示意，最终按真实 FOV 调）。
- **不以真实碰撞大量压窄通路**：可以让装饰看起来过量，真实通路与必要互动区域由项目碰撞规则保护。
- 中段留下“床上的一小块干净床单”或“未被杂物吞没的一张空椅”作为视觉反常中心。
- 站在通道靠内一点，玩家看见堆体里似乎有一个形成人形的空洞；注意不是直接生成隐形敌人。
- 允许光源被大件遮挡制造窄束光与深阴影；不能全黑。

**三种叙事变体**：`domestic_hoard` 家庭物件→失踪者；`archive_flood` 档案→记录重复；`toy_barricade` 玩具/布偶→消失的童年。

**最低成本版**：少数不同尺寸的纸箱、书本、布罩、旧椅和低成本墙面贴图；主堆可由静态组合模组负责，个别可拾取物件放在安全区。勿让物理引擎实时堆叠 300 件物品。

**失败示例**：像垃圾回收场随机散落；所有道具都能点击导致交互噪声；通路完全堵死；不同来源的材质尺寸不统一；整体没有被注视或被遮挡感。

研究方向：`Resident Evil 7` 住宅环境细节、`Hereditary` 的“生活真实→囚笼”、`Mad God` 的手工堆积和工业遗迹。

## 3. HERO N03｜血色房间 Crimson Room / Red Takeover

**目标**：不是简单“房间开一盏红灯”，而是让玩家感到这个房间正在被**某种红色意识/仪式/污染**接管。可分为三个原创版本。

### A. 灯光侵占

- 仍是普通走廊/客厅，红光来自一盏异常稳定的墙灯或门缝后。
- 正常暗灰表面仍能辨认；红色跨越门框制造强烈色彩边界。
- 进入区域后红色吞掉中景，出口门沿仍有少量冷白反差。

### B. 材质渗出

- 角落首先变深锈红，墙纸接缝沿重力方向出现暗红的流挂，地面有不均匀的湿润反射。
- 材质上是“从一个来源向外扩散”的**方向场**，不是整个房间所有墙都刷同一纹理。
- 可用低成本局部 decal/材质变体表达；高度写实、明确血腥不是强制选项。

### C. 帷幕 / 仪式红色

- 红色来自少数颜色浓重的布、纸或连续垂挂物；布幔遮蔽房间真实边界。
- 严格中轴的空座位、祭台或者唯一镜子作为中心；地面/幕布图案必须原创，不照搬《双峰》。

**颜色提案，不是固定 RGB 指令：** 深酒红（主基底）+ 灰褐/黑褐（结构）+ 极少量偏青冷灰（出口识别）+ 暗红反光（局部证据）。细节反差要足以看见人手、门、地面边界。

**镜头**：入口有清晰红色门槛→进入感到空间被单色支配→靠近发现红色材质有分层/纹理/规律→回望看到正常世界仍在门外。

**最低成本版**：现有房间+局部红光+1–2 款材质+少量贴花+几件仪式化家具。无需粒子血雨或动态闪烁。

**失败示例**：全屏色相滤镜、门出口辨识消失、任何房型都统一红色、不存在光照因果、过度频闪、直接复制《双峰》的完整设计。

研究方向：`Suspiria (1977)` 的颜色作为世界规则（摄影师访谈）、`Twin Peaks` 舞台性和 `The Shining` 的对称手法。

### 4.1 对每一份候选自动寻找“形体主角”

每个主题必须能归入以下一种主图形：

- **群手/群椅/群摇篮/群门**：重复单位产生方向与组织。
- **堆积山/纸瀑布/花墙**：材料密度和层叠产生体积。
- **幕布森林/衣柜森林/灯箱**：重复的竖向或横向建筑节奏。
- **肉质边框/血红浸染/潮湿表面**：材料感染和色彩梯度。
- **空椅/缺一床/空画框**：大量规律建立后，用一个“缺席”制造恐惧。

千万不要把“全是手的走廊”与“满墙眼睛”“堆满玩具”“红光闪烁”不加节制地一次组合。**主主题先得到视觉通过，再考虑辅助主题作为远处呼应。**

## 5. 随机组合不是乱抽：指定兼容关系

| 主主题 | 可共存的辅助元素 | 不应在同房强行共存的元素（非绝对剧情禁令） |
|---|---|---|
| 手走廊 | 暗灰旧墙、细条顶灯、冷光出口、局部镜框遮挡 | 大量花墙、纸海、满房红闪烁和复杂解谜道具 |
| 堆积屋 | 遮挡、失踪者日常物品、单个清洁区域、窗后人影错觉 | 每件都泛光、每件都能动、多个不相干怪物 |
| 血色房 | 严格中轴、深布、少量空椅、材质流挂 | 再加霓虹彩虹、逐个家具独立跳光 |
| 天花布幔 | 高处静止轮廓、淡灰粉、低位家具 | 漫天雨点粒子、复杂镜面反射 |
| 档案纸浪 | 过度重复、统一日期、单一空缺档案盒 | 另一套人偶/脚印/手爪大潮与其争抢画面 |
| 肉质门框 | 湿润材质、肋骨般边框、一扇普通木门 | 和现成游戏的标志角色同款造型 |

组合算法建议：先配**一个主主题（70% 注意力）**，再加**一个强化它的辅助语法（20%）**，最后用**一个可被发现的反常细节（10%）**。这个比例描述的是**画面注意力**，不是实际物件数量/算法概率。

## 7. 视觉语法独创性与否决标准

- 每份房间至少回答：“它与参考游戏的具体场景有什么明显不同？”可通过材料、空间用途、配色、发现方式、几何顺序、叙事规则区分。
- 查到 Little Nightmares II 的手/人体模型不能复制人物及特定场面；我们借用的是**重复肢体的空间心理效果**。
- 查到 Twin Peaks 的红房间不能直接使用红帘 + 黑白 V 字地板 + 原样家具的组合。红色可以，但空间语言、物件关系必须原创。
- 参考图片不得下载直接贴图或作为 AI 再绘的 1:1 输入；若需要合法资源须提供来源和具体授权。
- 不能把模型穿模、材质错误或物理崩溃当成故意超现实。

## 8. 建议优先验证的三间：同一技术，三种心理

1. **墙纸走廊 → N01 手走廊**：检验几何锚点、实例化/贴花、真实视角、碰撞路径。
