# 《心里有鬼》程序化恐怖房间审美与技术验收｜QA v2.0

> 用途：每次研究后、预览后、代码接入后均执行。**低强度与高强度验收标准不同**；强场景可以允许整房大面积异常和大量重复实体。本表不代表已执行任何项目测试。

## 0. 一票否决的 P0

- [ ] 房间无法正常进入/离开、门扇被遮挡、出口不可见或导航路径断裂。
- [ ] 玩家、交互对象、现有敌人/事件触发区发生不可接受的穿模或碰撞。
- [ ] 未获许可改变随机地图拓扑、游戏剧情、敌人行为、输入和控制或已有锁定美术。
- [ ] 同 `seed + roomId + visualVersion + 相同配置` 不能稳定复现；美术随机破坏地图原有 seed 顺序。
- [ ] 运行帧率显著劣化、手模型/杂物独立网格数量没有实际预算检查、重要页面崩溃。
- [ ] 参考来源违法或不明确授权的图片/3D 模型被直接用于游戏发行；研究图被当成可商用。
- [ ] 短时间强制全屏高频闪烁、剧烈抖镜、不可关闭的强刺激；没有可接受的替代方案。

**判定方式：P0 任意一项发生即 FAIL；该房间只能保持旧版或降级到稳定预设。未经实测的项目写 UNKNOWN，不得改成 PASS。**

## 1. 生成前：恐怖规律审查

- [ ] `normal_function`：原来的房间是什么？玩家第一眼能辨认吗？对于抽象高潮房，是否仍有可识别的建筑参照？
- [ ] `fear_question`：玩家在这里应该问自己什么？是被看、被围住、被吞没、被欺骗，还是现实物理出了错？
- [ ] `governing_rule`：至少能写成一句严格的空间规则（例如“所有手沿玩家前进方向伸出，密度越往深处越大”）。
- [ ] `intensity`：房间强度在已有叙事角色允许范围内，不把普通连接房随便变噩梦终局。
- [ ] `design_signature`：与前两间房相比，是否至少有形状、色彩、物件族、观察方式之一明显不同？
- [ ] `source_trace`：至少有一条可核查影视/游戏/艺术家链接，已区分“研究原理”和“游戏自创方案”。

## 2. 三种主场景专项审查

### N01 手之走廊

- [ ] 从入口能辨认走廊与远端出口；不是手群直接堵在镜头前。
- [ ] 手/臂至少存在 **稀疏区 → 增密区 → 主奇观 → 出口减密** 的节奏；或者文档解释了另一种清晰的方向规则。
- [ ] 手有高低、近远与朝向组织；大中小簇关系成立，不能均匀随机悬挂。
- [ ] 手影子/遮挡与灯具关系可信；在第一人称看有前景和深度。
- [ ] 默认是可验证的非碰撞装饰；有动画/碰撞/敌意行为必须走已有事件授权。
- [ ] 用已获授权的原创/可商用模型，不复刻现有知名作品的独特形体。

### N02 堆积之屋

- [ ] 看得出至少一个原来的生活用途/主人线索；不是“资产随机垃圾堆”。
- [ ] 大件→中件→小件三级组织完整，至少一个主堆有强轮廓，另外有一块明显空域。
- [ ] 中件按一个可解释的同族规律堆积（年代、用途、材质、事件）。
- [ ] 预留可行走路径及交互窗口；禁止用物理堆叠实时生成数百刚体。
- [ ] 玩家从物件缝隙能看见一个剧情焦点或发现暗示。
- [ ] 总光照仍可辨主要走道、堆体边缘和出口。

### N03 血色房间

- [ ] 至少存在**两种不同深浅的红色及一种相对中性的参照色**（方向性要求，非死板数值）。
- [ ] 红色由光照、材料、装饰或渗出方向场驱动；不是无源全屏红滤镜。
- [ ] 从正常房进入红房有明确色彩门槛，玩家看得出自己进入了另一个情绪状态。
- [ ] 门、交互、障碍边界不因为红色丧失可读性；手电等现有机制仍有效。
- [ ] 不是复制《双峰》的整个红幕/几何地板布景。
- [ ] 动态闪烁、重度色差与晕眩镜头均有关闭/减弱方案；优先静态层次。

## 3. 通用的 4 视点构图验收

| 观察点 | 要验证的真实玩家经历 | 截图建议文件 |
|---|---|---|
| `entry` | 入口自然机位：原用途、主视觉、出口大概方向 | `entry.png` |
| `forward` | 靠近主奇观：数量/材料/色彩的方向性是否强化 | `forward.png` |
| `reveal` | 侧移/抬头/观察缝隙：有没有第二层恐惧信息 | `reveal.png` |
| `lookback` | 回望：空间是否仍有设计过的连续性和可读路线 | `lookback.png` |

- [ ] 截图来自**实际运行的游戏**，不是用概念图或外部参考图冒充。
- [ ] 同 seed 固定相机视角比较 `baseline` 和 `candidate`；如果仅测试灯色，**不能同时变化几何和物件**。
- [ ] 出口/提示能被可靠看见；恐怖发现可以错过，但关键剧情交互不能只靠毫厘级视角触发。
- [ ] 遮挡是合理的真实几何/布/格栅；不是 z-fighting、模型穿墙或资产卡顿。
- [ ] 上下层、天花板、窗后轮廓出场在真实游戏俯仰/FOV 范围内。

## 4. 双标准审美评分（每项 0–5 分）

### 4.1 L0–L2 心理恐怖房

| 评分维度 | 5 分是什么样 |
|---|---|
| 生活真实感 | 家具用途、人体尺度、年代、光源合理，像真实有人住过 |
| 小异常力量 | 不靠鬼或血也让玩家意识到“东西不太对” |
| 观察设计 | 入口、遮挡、远处、回望均自然可玩 |
| 叙事关系 | 单件关键物与周围正常物有可追溯的关系 |
| 邻房反差 | 与刚经过的房间保持色彩、密度、发现方式差异 |
| 完整与原创 | 构图明确，不能辨认成照搬其他影视场景 |

### 4.2 L3–L5 侵蚀/噩梦房

| 评分维度 | 5 分是什么样 |
|---|---|
| **主导规律明确** | 一句话能解释为什么整间房变成这样；所有异常都属于同一设计系统 |
| **密度与轮廓** | 有一个明确主物件团块，且有疏密、大小、前后层级，而不是满屏平均细碎 |
| **心理或生理不适** | 数量、尺度、材质、颜色、空间侵犯至少有一项做到强烈且可信 |
| **第一人称舞台调度** | 入口震撼、靠近升级、二次发现都有设计；可形成精彩演示画面 |
| **可玩性/性能** | 看得见出口、有足够路径、资产实例化合理、在目标设备稳定 |
| **原创与节奏** | 不直接临摹原作；它是高峰，前后房间反差清楚 |

**建议审美通过线**：无 P0；相应六维均分≥4 且单项≥3；实际项目负责人可按 Demo 时长调整。`UNKNOWN` 不可视作通过。

## 5. 不准用“看起来很恐怖”替代以下检查

- [ ] 物件数量是受控的；没有从网上下载一堆模型直接丢地面。
- [ ] 颜色是**构图**而不是屏幕滤镜；深红房也能看见重要边界。
- [ ] 高强场景后有恢复平静的空间；没有视觉疲劳。
- [ ] 影子不是单纯渲染故障；特殊物体存在于可以被玩家观察的合理位置。
- [ ] 现场演示设备的 GPU/CPU/浏览器性能被真正测试；没有声称“应该没问题”。
- [ ] 如新增音频/动态变形，已清楚注明可能影响哪些已有机制和设置。
- [ ] 手、脸、眼、真人相片、外部搜索素材均明确注明原始来源/授权/原创生成流程。

## 7. 最后一条独立审美问题

> **心理房**：如果去掉所有鬼与血，只看静止家具和门框，是否依然隐约令人不安？  
> **噩梦房**：如果不告诉玩家“这是恐怖游戏”，只看入口一张静止截图，是否能一眼识别某条现实规则正在接管房间？  
> 两个问题分别回答，不能拿心理房的“少量异常”标准压制噩梦房的大胆，也不能把噩梦房的满屏密度当成所有房间的最低合格线。
