> **核查日期：2026-10-31。** 本文列出本次实际搜索到的网页与材料，并说明每个链接**值得让 Codex 研究什么**。不代表已逐帧观看所有作品，也不代表某一用户上传图片的原作者已确认。网页随时间变化，Codex 执行时应重新打开、记录时间与证据层级。

## 0. 搜索与事实纪律

- `PRIMARY`：开发者/电影制作人/摄影师/美术总监的直接访谈、官方游戏发布页、原作者页面。
- `SECONDARY`：专业媒体报道、评论、研究文章。可以给设计分析，但不得假装是导演明确表达的意图。
- `ART ONLY`：Pinterest、截图、用户自存参考、未确认原作者的照片，只用作视觉分析；不能当可商用资源。
- **每条配方至少需两种独立参考机制**：如“悬疑视线”来自电影 + “可检验变化”来自游戏；真正布景必须是本项目原创。
- 对外引用用链接，不复制别人镜头素材、纹样、角色或原作资产。无法核实的具体镜头位置填 `scene_not_verified`。

## 3. 艺术家：Trevor Henderson 应如何被正确参考

| ID | 来源 | 事实与研究用途 |
|---|---|---|
| A01 | [Trevor Henderson 个人 About 页](https://trevorhenderson.format.com/about) | 本人网站确认其为插画家、恐怖生物概念设计师，创作过 Siren Head、Cartoon Cat。**这并不证明用户的 U06 窗户图片出自他。** |
| A02 | [Trevor Henderson 访谈：伪发现影像与照片结合](https://reactormag.com/artist-trevor-henderson-siren-head-interview/) | 本人谈到要让虚构生物在照片中看起来像拍摄时实际存在；研究**摄影视角、光色匹配、遮挡边缘、低清的合理性**，而不是复制他设计的怪物。 |

给程序的转译方式：

1. 必须先建立**普通照片/普通房间**的真实透视与年代风格。
2. 不正常形体应该符合本空间的**遮挡、投影、景深、纹理粗糙度/曝光关系**。
3. 最好的“被发现”往往在高处、门缝、玻璃另一边、远处、背景，而非正中央摆一个清晰大怪物。
4. 在 **intensity 4–5** 的强场景中可以让整间房变得不正常，但仍要保留 Trev​​or Henderson 方法中的**有尺度参照的空间可信度**。
5. U06 作者未知，不能自动标成 Trevor 原图或用作商业游戏贴图。

## 6. Codex 不应误做的六件事

- 不要把 **用户图片 U06** 写成 Trevor Henderson 的作品——尚未核查作者。
- 不要把所有同类影片的某种场景写成“导演亲口表示设计目的是 X”，除非来源原话证实。
- 不要从 Pinterest/图搜结果直接抓素材用于发布游戏。
- 不要为了看起来像 Scorn 就临摹其生物机械资产或直接复制经典形体。
- 不要为了像《双峰》就复制红布幕+黑白尖角地板+同款椅子整个组合。
- 不要联网研究停在大量图片链接上：**每一条参考必须产出可执行的 `placement / lighting / camera / safe_path` 规则。**
