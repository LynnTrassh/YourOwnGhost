## 4. 六套原创构图卡

以下数量／高度／密度是初次预览预算与构图目标，不是实测合格参数。entry → forward → reveal → lookback 四机位均需后续从合法站位记录 xyz/yaw/pitch。图示只表示关系，不是按比例导航图。每套先按 L4 设计；不把 short/rest 房偷偷升级，L5 留给有明确高潮许可的后续主题。

### N01-A「指向空位的手潮」——轴线收束

原用途是旧楼通道。恐惧命题：“这些手不是乱抓，它们在给某个看不见的经过者让路。”主规律：所有手沿长轴趋向一个空的轮廓中心，密度先增后减。

```text
入口旧墙 → 单侧短簇 → 两侧错层手潮 → 远端视觉收束峰 → 低密出口
               └──── 原有净空／地面连续可见 ────┘
```

主轮廓是两侧手群在透视中构成的“缺口”；不把 .65 m 手臂拉长跨越 5 m 通道。三簇：近处 2 个局部轮廓，中段左右各一组错层，远端高处同向簇形成峰值。初次用 12 个实体手（2/4/6）测试，若仍像挂钩，先改方向与遮挡，不自动加到 40 个。入口留完整墙纸和一盏正常灯，出口两侧减密；每簇内顺着同一弧线，簇之间留整块暗墙。

四视点：入口先看到正常廊道与远端异常齿状轮廓；走近认出手掌和沿程递增；侧移看清所有手围绕同一空隙；出口回望时空隙轮廓成立，手群没有换位。冷灰绿墙、灰白手、少量旧锈色，沿用可见灯具作侧向擦光，手电显露近手指缝。只对少量主簇试现有阴影，背景手不逐个投影。

复用：已导出手臂、旧墙纸、既有门／灯。缺：墙缝安装景片、额外手势／低模远景代理、簇布局与视线验证。现有唯一手型只能证明结构，不足以最终做满墙多样性。依据 G05 的身体尺度、G06 的建筑主题、F02 的移动视角；手群组织与空位是本项目原创。

保护：全部手的变换后真实包围盒退出导航扫掠体积，避让门扇和 TH01 观察线；不能以无碰撞为由伸进玩家身体。当前位置只能先独立预览；缺合法墙带则退为少量墙面手印候选，手印素材仍需原创制作。

### N01-B「反向迎宾廊」——去时像墙饰，回头像夹道

原用途仍是通道。恐惧命题：“我以为它们朝前，回头才发现它们都朝来路伸手。”主规律：每簇沿既有转折／墙肩背面朝入口偏转，数量大但视角相关，完全静态。

```text
入门：正常墙肩 + 半截手背 → 穿过肩部 → 侧面显现掌指 → 回望多簇合成夹道
```

主轮廓是一面倾斜的手掌浪潮，入口侧保留约一半完整墙面作为呼吸区。三组按低／中／高错开：低簇贴墙脚边缘，中簇藏在真实转折后，高簇沿顶墙接缝汇集；不凭空增加挡路门框。低簇不能占脚边路线，高簇不能悬进相机。姿态角度有方向偏置，不做均匀随机旋转。初次 8–12 个实体手，其余密度靠同源原创浅浮雕候选，不能把错误阴影假装成灯投影。

四视点：入口仅手背碎片和普通灯距；forward 看见数量递增；reveal 在合法肩部侧移认出完整掌面；lookback 手群共同朝门伸展，而入口仍有清楚明暗边界。灯从行进侧后方擦过指缘，回望得到可读轮廓；不加怪脸、红闪或新敌人。手的“忽然出现”来自几何遮挡，不来自摄像机背后随机生成。

复用与缺口同 A；更依赖真实墙肩。i 形中央段太短或无合适反向壁面时不适配，改选既有 elbow/ring 的合法段，不改房壳。参考 A02 的现场可信度、G01 的未知与回看；不宣称这是《P.T.》某个现成镜头。

### N02-A「归档到天花板」——一高一低的档案峡谷

原用途是旧档案室。恐惧命题：“这里把所有生活都归档了，只留下一个永远空着的位置。”主规律：同规格档案沿一个归档方向过量复制，吞没房间用途。

```text
高堆／书架骨架 ███████      远端干净空槽
                 原有可达路线 ───────→ 门
低堆／分拣桌   ▂▃▂         近处正常阅读组
```

主堆在一个非门墙段，目标最高约 2.5–2.65 m（需验证约 3 m 室内净高），入口画面占远墙约三分之一；另一侧低堆不过度遮眼。四簇：架内归档、桌旁待整理、墙角积压、唯一空槽。柜／书架搭骨架；盒、纸捆搭中景；少量同样标签作近景，标签先用非交互标记，不伪装新谜题。主堆从墙边向上增长，平地不均匀撒纸。

四视点：entry 看出书桌与存放功能及一高一低轮廓；forward 发现所有盒有同一归属标记；reveal 从低堆上方看到干净空槽，背板仍封闭、不误导为可走洞；lookback 空路连续，原门没有被堆体遮住。灰褐纸、尘绿柜、暗木，已有绿罩台灯照近桌，主堆侧边由现有顶灯补轮廓，不把远处细节全部照亮。

复用：archive-shelf、filing-cabinet、writing-desk、copy-table、dining-chair；代码已有纸／书的程序几何，但需另建可复用组合而非直接调用私有函数。缺独立档案盒和高堆组合；先用 4–6 个低成本模块证明体量，无需再生成一套家具。

通路：所谓 S 形只可顺应**已经存在的路径**；本轮不能通过移动碰撞家具造弯路。装饰堆需位于既有实体占地或不可达贴墙区，超出则交程序方规划真实 AABB。保护 IN02 抽屉、溢出端及观察线；因为主题与 IN02 冲突，当前实例只供几何预览，不能宣称正式可投放。参考 F05 的生活来源、F07/F08 的材料一致性，原作用骨和工业废料不进入本方案。

### N02-B「未完成的搬家」——一把干净椅子被岁月包围

适配原用途为客厅；在档案宿主先作“迁移中的旧阅览室”预览，不强制替换实际 preset。恐惧命题：“所有东西都已打包，唯独这个座位一直在等人。”主规律：同一生活用途的物件被逐层封存，朝一个空座形成弧形堆积。

```text
门框前景 → 低纸捆 → 高柜与叠盒半围合 → 中心干净椅／阅读桌 → 留出退路
```

三簇按生活动作组织：阅读（书／桌／灯）、收藏（柜／盒／布）、准备离开（成捆纸物）。主堆是一侧高柜上的阶梯轮廓，另一侧低至膝部；空座旁只留一本未包好的书。数量异常集中在盒与布，不混入电视、虫、骨、玩偶等不同主题。布盖顺着家具真实支撑垂下，不让整柜漂浮或在玩家头顶悬空。

四视点：入口首先辨认生活功能和露出的椅背；forward 从堆隙看见干净座面；reveal 侧移发现所有标签／包裹开口朝向那把椅子；lookback 原入口被堆体框住但完整可读。局部旧暖灯留给空座，尘绿／纸黄大堆退暗，明度由近低堆到远高堆分层。

复用：档案宿主现有书桌、餐椅、档案柜；未来 parlor 可换为现有沙发、茶几、陈列柜，**必须由已规划锚点选择，不挪原家具**。缺箱体组合、布盖。第一版若空椅位置不合法，就以现有桌面“干净空矩形”替代；不为了构图新加可穿透椅子。依据 F05 人物用途、G03 物件关系和 F08 材料成组，非复制任何具体“囤积屋”。

### N03-A「红色围住空位」——偏轴仪式而非全屋滤镜

原用途供奉室。恐惧命题：“红色占了整间屋，唯独有人该站的位置仍然干净。”主规律：深红布与红光向同一供奉焦点收束，并围出清楚空位。当前 U 形宿主焦点偏轴，不强行搬到房中心。

```text
冷灰门边 → 灰褐近景／原有供奉物 → 酒红侧簇 + 暗红后景 → 焦点旁未侵占空位
```

三簇：供台附近原有陈设、左右墙的少量直条布、远墙红色承接面。主轮廓是供奉群体外的凹形深红背景；地面和玩家路线保持暗中性，布不垂进道路。RI02 的猫／花与跪拜者仍为叙事焦点，**不能新放空椅抢走原有空位或改摆位**；独立无事件版才可测试空椅构图。

四视点：entry 看到明确红色门槛与原事件关系；forward 区分酒红织物、暗红光区、灰褐木材；reveal 看清红色在已有空位边缘中断；lookback 唯一退路的门沿保留亮度／冷灰差。现有壁灯试红色主光，顶灯或门外漏光保留中性；最多从现有灯中选 1–2 个主职责，不新增一圈实时灯。`lockdown` 全灯改红不直接用，`split` 也先核验实际灯位。

复用：红绒帘、供桌、跪凳、柜、已有灯具。缺：按空间区域控制的绑定与事件灯优先权；不需要新角色／血雨／动态图。依据 F04 颜色的空间分割、F03 简洁关系；用原有地板和直线旧布，绝不复制黑白 V 字地板。

### N03-B「向上返潮」——红色从一个点违背重力

原用途供奉室或旧会客厅。恐惧命题：“这不是洒了一地的血，红色正在沿墙回到某个源头。”主规律：暗红痕迹从一个墙脚源点向上收束，方向一致、边缘渐弱；用反重力的静态痕迹暗示异常，不模拟流体。

```text
灰褐入口 → 地脚稀疏锈红 → 一处湿暗主堆面 ↗ 向上汇聚 → 源头附近干净边框
```

三簇按同一个方向场组织：地脚薄层、墙纸接缝中层、源点上方主色块。主视觉是不均匀的红色楔形，另一整片墙保留原色；不覆盖全屋同款血纹。几件家具朝源点的一侧出现颜色反射，背面仍是正常旧木。RI02 的实际喜欢物不能被污染改意，源点应在其旁侧非交互墙面，若争夺焦点则只供独立预览。

四视点：entry 先见红色来自特定角落；forward 看清哑光锈红与湿暗酒红；reveal 靠近发现痕迹向上而非向下收束；lookback 门外日常颜色仍成立，地面边界可辨。单个现有壁灯贡献红光，中性侧光／手电负责解释粗糙度。普通 MeshStandardMaterial 不会自动产生真实镜面倒影；首版是湿润高光，不能许诺实时反射或体积光。

复用：现有房间模型、墙面／地面材质体系、灯具。缺：原创局部流挂／粗糙度遮罩和局部材质隔离，避免修改共享材质污染邻房。不从外部剧照切血纹。参考 F04 色域、G08 真实而略湿的材料；反向流挂及保留干净边框是原创规律。若新增贴片闪烁／排序失败，则保留正常表面，先回到 A 的静态灯光试验。

## 7. 最小实施与验收建议

优先预览 **N03-A**：可最大程度使用现有灯与布，且宿主已有 major 供奉语义。第二做 N01-A 的 12 手静态主簇；第三做 N02-A。B 方案作为同房对照，每轮只替换该房的一套配方，不同时接入六套。

1. 下一轮新增独立 `art-source/horror-director-v2-preview/` 与独立 `src/art/horror-room-variants.js`，读取最终计划；页面按需绘制。先默认原版，显式启用单房候选，提供恢复／释放。授权后的实际交付为独立预览目录、src/art/crimson-room.js 与 src/art/encounter-flash.js，见实施说明；这里保留原设计建议。规划、world/main、灯光模块等旧文件不自行接管。
2. 适配层只接收 plan／已选 recipe／placement，不写 plan。开关前后完整 plan、cells/doors/edges、content/story/threat/chase 与碰撞／导航摘要应相同；异步模型失败保持原外观，dispose 恢复材料／灯光并释放自有资源。
3. 房壳设计预览与事件兼容预览分开标注：前者证明构图，后者运行原事件。TH01、IN02 不因预览需要而从正式计划移除；若兼容失败，拒绝该绑定。
4. 保护实际 1.6 m 门洞、既有门前区、每条现存门到门路线及事件交互／视线；使用 PLAYER_RADIUS .24 m 扩张体积。所有新增实体外形均不得侵入通路，包括不碰撞的手、布、堆体。既有家具外新增可触达大件必须由程序方同步占位，不以 `nonBlocking` 绕过。
5. 同 seed／输入／版本、固定 72°／1.65 m／曝光 1.1025／视口／DPR／VHS／手电／事件时间，记录 baseline 与 candidate 的 entry、forward、reveal、lookback（至少 8 张），记录真实坐标与 yaw/pitch。审计阶段未采新截图；后续首批浏览器验证见实施说明，不把它扩写成六方案全 PASS。
6. 首个手群预算从 12×6033=72,396 几何三角形／每个可见绘制 pass 起；40 只即 241,320，阴影还会重复绘制。实例化减少提交但不减少三角处理，需低模／裁剪／选择性阴影。堆积优先 4–6 个模块合批，不运行刚体堆叠。红房优先不增加灯数、不增加实时反射或体积效果。
7. 当前已有性能诊断指出首次灯光变体准备可能停顿，见[既有性能记录](../scene-performance-v01.md)，它不是本轮测量。候选必须实测资源冷启动、热态帧时 P50/P95、首次走近／回头／跨门最长帧、绘制／三角数与失败加载；同设备同条件对照。未测目标硬件不能称性能达标。
8. 玩法接入后运行 npm test、npm run build；通过现有门交互、同房进出、完整事件、第二层、暂停恢复与低刺激设置。静态六方案本身不要求闪烁或晃镜；“银松镇闪片”已确认是怪物出现时插帧，具体叙事触发仍待策划接入，不能成为全屋常驻特效。
9. 按 v2 QA 六维审美与 P0 检查：高强度看主规律、体量、发现和可玩性；无 P0 后再由用户做审美与真人试玩确认。没有这些证据不扩大到程序化池。

## 8. 后续原创方向储备

- **借来的窗光（L2）**：旧客厅里只有一组物件呈现窗格形明暗；走近发现那面墙没有窗。先用原创静态材质印痕，保留实际灯影一致，明确“画在表面”与“真实投影”的区别；不增加假导航出口。
- **墙纸缝合廊（L4）**：同一种墙纸接缝从稀疏竖线逐渐变为贴墙褶皱，尽头保留普通木门；全房只讲材料增殖，避开 Scorn 既有生物机械造型。
- **倒置的晾晒间（L3→L4）**：湿旧织物沿顶部逐渐增密，越靠近地面越空，正常矮柜给尺度；从出口反看才连成倒置生活空间。无动态布模拟，不改玩家高度或屋顶碰撞。

三者均为新设计储备，不占当前任务资产预算，也不冒称已有运行支持。
