# 开工卡公共约定

日期：2026-10-31。81 张范围卡加 5 张编排实施卡，共 86 张。卡片是规格与验收单，不是已实现清单或共享文件锁。

## 依据与维护

场面与台词以 [剧本总集](../script-catalog.md) 为准；来源资格与密度以 [剧情编排](../content-scheduling.md) 为准；接口遵守 [运行规范](../script-narrative-runtime.md)。[统一执行顺序](execution-order.md) 管理本轮批次，[审查记录](review.md) 记录问题与剩余待定。代码现状以当前代码、开发记录及对应任务证据为准，计划接口不能当已有 API。

## 开工与责任

1. 读取根目录 AGENTS.md、协作约定、当前差异及任务。每批代码工作建独立 docs/tasks 任务，明确实际范围；本目录不能代替任务认领。
2. 玩法方拥有状态、编排、碰撞、共享场景及主入口；chen 拥有独立美术模块与资源。先交接口，再集中接入；不同时改共享文件，不替对方承诺排期。
3. 区分开工前置、能力切片、同组验收与运行时事实。S02 是能力总卡，P01–P04 是具体实施，P05 是诊断；不得各实现一套编排器。能力卡可随场面逐步完成。
4. 状态按“规格已列 → 待实施核对 → 灰盒可演示 → 视觉音频完善 → 已验收”登记。已有原型复用，缺少音频／资源如实登记；灰盒入池与完整验收分开。
5. 本轮只安排和修正文档，不更改运行版本。提交／推送按用户明确授权。

## 状态与事件

实例独立于渲染对象，保存实例身份、梦层、阶段、观察事实、永久变化和消费记录。观察默认需视野、遮挡、可辨认面积及连续曝光；0.8 秒为调试值。跨门、靠近、停步等仍按各卡明示触发，不能全部改成观察触发。

- 未观察就离开不消费观察依赖；死亡传送不是正常过门。回访变化在合法正常离开后提交。
- 活动范围包括当前房、可透门／观察窗看到的对房、镜面与监控引用的对象，以及需要听见的配对声源。仅在没有活动视听关系时冻结普通持续动作；不能按玩家 roomId 把隔壁演出或声音停掉。暂停冻结全部游戏演出时间。
- 永久变化和中断动作的恢复点保留，重建模型不重演。临时追逐按具体卡复位；死亡不把所有动画无差别归零。追逐持续模拟不等于持续移动，TH01 仍须失视即停。
- 普通死亡保留层、图、永久变化与真实事实；假醒只读取 IN04、B27、B28 及主流程白名单。新层按已确认计划装配，不在进房时重抽内容。
- B13–B16 同一追逐实例，四段为联合验收组，不是循环开工依赖。B26 复用主流程；B27/B28 计入前置尾声；TH 示范不扣 Meta 评论预算。
- 预览 runId 与 debug 事实隔离；未看见、未触发、能力缺失均有拒绝原因。

## 旁白、声音与资产

台词只在总集维护。每句登记 lineId、原文位置、事实守卫、语气、音频、字幕时轴、消费范围和版本。没有录音可验证字幕状态，不能记为配音完成；声音关键剧情需有实际关键声才能进入正常池。

全局同时一句；危险／关键声音窗口优先。离房、阶段变化和死亡使过期句取消，不排队追播。暂停续播游标，死亡已开始的句子保持消费。行为评论每局最多两次、同类一次；场面与威胁示范不扣这项预算。关闭语音或资源失败不能锁住演出；需要“实际听过”的事实不伪造，允许错过并正常通关。

当前合成占位音效已撤下。S05 从已试听素材接入；不把保留的试验源码当作音色已通过。威胁外观由确认的恐惧及能力适配决定，声音不默认统一石头摩擦。

资源交接包括路径、尺度、原点、朝向、包围盒、材质、动作／变体、创建更新释放和性能记录。静态 GLB 不代表镜面、形变或动作完成。先预约剧情空间，再摆家具，所有版本复验门口、视线与碰撞。固定 11 种九宫格掩码与外框边中门位不变；不加长走廊或独立隔断来硬凑剧情。

## 验收矩阵

每张卡填写 V01–V09 的通过/失败/不适用及理由，不能默认整列通过。非危险房的死亡测试可以在事件前后从其他威胁死亡回床；调试死亡仅作补充。

| 编号 | 场景 | 要证明的结果 |
|---|---|---|
| V01 | 初见与合法触发 | 不看说明能辨认关注点；事实成立才变化/评论；允许随时离开 |
| V02 | 忽略、遮挡、未观察离开 | 不能提前消费观察依赖；进入触发型依自身规则，不误套观察门槛 |
| V03 | 离开、回访、场景重建 | 阶段正确，永久变化不回退；中断动作恢复可读，不重复触发 |
| V04 | 暂停与恢复 | 观察、动作、字幕、声音计时一致冻结；旧回调不误报完成 |
| V05 | 死亡前后 | 层与地图保留；未观察不消费，已提交不恢复，临时追逐复位 |
| V06 | 假醒与重开 | 只有一次主要假醒；只读声明的前置；新局无旧实例/语音/加载残留 |
| V07 | 声音、字幕与互斥 | 原文及语气正确；关键声清楚；过期取消；静音和资源失败不锁进度 |
| V08 | 合法随机布局 | 可达观察位、自然回程/配对/连续路径成立；出口不堵；固定种子可复现 |
| V09 | 实际表现与性能 | 正常游戏路径可读且运行稳定；记录目标浏览器、帧耗/资源预算和真人体验问题 |
