# 心里有鬼 Your Own Ghost

以个人喜好与恐惧为素材的第一人称梦境恐怖游戏。使用 Three.js、Vite 与 JavaScript ES Modules 开发。

## 协作入口

双方 AI 开工前阅读 [AGENTS.md](AGENTS.md) 和 [双人协作约定](docs/collaboration.md)。共同维护 main，按文件分工并行开发，共享入口由程序方集中接入。

## 本地运行

使用 Node.js 24 LTS，首次运行安装依赖：

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:4190/ 。服务仅监听本机。固定种子可用 `/?seed=42`；菜单支持应用种子、换一张地图与查看调试平面图。重新开始保留当前布局，换图会创建新局。

点击进入后按 E 起身，WASD 移动，鼠标环顾；靠近并看向门时按 E 开门，F 开关手电，Esc 暂停。无法锁定鼠标的浏览器可选择拖动视角模式。暂停菜单支持调整灵敏度与重新开始。刷新会重置当前进度。

## 当前范围

单层随机灰盒地图：固定八个房间的用途与关系，使用 3×3 模块掩码组成方形、长方形、十字形、L 形、T 形、U 形、回字形、缺角方形、双角缺口、工字形与直条形共 11 种轮廓，种子改变轮廓、朝向和间距。每模块 5×5 米，完整九宫格为 15×15 米；相邻模块属于同一房间，默认无隔墙。出生卧室沿用 seed 42 的固定样式，轮廓、门窗、家具、色调与出生视角不随种子变化；其余房间内部可组合中央绕行、隔断分区、交错书架或沿墙陈设，柜台、隔断与书架参与碰撞和路线生成；装饰颜色使用独立随机子流。包含猫房预留区、自然回访环、左右分支、汇合与出口；菜单可查看包含家具占地的平面图和计划标识。

保留起身、移动、墙体及家具碰撞、开门、手电、暂停和重开。卧室门暂为上滑占位门，其余连接为开放门洞。到出口标记附近按 E 完成地图巡查；这不是游戏剧情结局。尚无猫房事件、旁白、怪物、两层假醒、声音或 AI 服务。连接关系目前固定，尚未实现任意拓扑和随机剧本编排。

## 验证与构建

```sh
npm test
npm run build
npm run preview
```

构建输出位于 `dist/`，预览地址为 http://127.0.0.1:4191/ 。

- `src/state.js`：独立的游戏状态。
- `src/collision.js`：平面碰撞与分步移动。
- `src/planning/`：房型、种子布局、碰撞校验、有限重试与保底计划。
- `src/world.js`：将生成计划装配成场景、灯光和门，共用已验证的碰撞体。
- `src/map-preview.js`：纯数据计划的调试平面图。
- `src/main.js`：输入、游戏循环与界面。
- `tests/`：碰撞、状态、确定性、100 个种子通行、错误布局与保底测试。
