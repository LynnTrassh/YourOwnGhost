# 心里有鬼 Your Own Ghost

以个人喜好与恐惧为素材的第一人称梦境恐怖游戏。使用 Three.js、Vite 与 JavaScript ES Modules 开发。

## 协作入口

双方 AI 开工前阅读 [AGENTS.md](AGENTS.md) 和 [双人协作约定](docs/collaboration.md)。共同维护 main，按文件分工并行开发，共享入口由程序方集中接入。

## 本地运行

使用 Node.js 24 LTS，首次运行安装依赖：

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:4190/ 。服务仅监听本机。固定种子可用 `/?seed=42`；菜单支持应用种子、换一张地图与查看调试平面图。“从第一层重新开始”保留当前种子的两层布局并清空进度；“开始新的梦境”使用新种子。

点击进入后按 E 起身，WASD 移动，鼠标环顾；靠近并看向门时按 E 开门，F 开关手电，Esc 暂停。无法锁定鼠标的浏览器可选择拖动视角模式。暂停菜单支持调整灵敏度与重新开始。刷新会重置当前进度。

## 当前范围

两层梦境流程灰盒：每层按种子生成 8–12 间房与不同连接图，使用 3×3 模块掩码组成方形、长方形、十字形、L 形、T 形、U 形、回字形、缺角方形、双角缺口、工字形与直条形共 11 种轮廓，种子改变房型组合、朝向、位置和连接方向；门洞只允许位于完整九宫格外框四条边的中点，对应模块缺失时该方向不可连接。每模块 5×5 米，完整九宫格为 15×15 米；相邻模块属于同一房间，默认无隔墙。出生卧室沿用 seed 42 的固定样式，轮廓、门窗、家具、色调与出生视角不随种子变化；其余房间内部可组合中央绕行、留白空间、交错柜体或沿墙陈设，书架背面朝实体墙，中央绕行使用柜台；柜台与书架参与碰撞和路线生成；装饰颜色使用独立随机子流。从实际图识别环路、分叉、死路和出口路线；有合适环路空间时标记回访候选，没有时不强制生成；菜单可查看包含家具占地的平面图和计划标识。

保留起身、移动、墙体及家具碰撞、开门、手电、暂停和重开。卧室门暂为上滑占位门，其余连接为开放门洞。第一层靠近出口标记、视线未被挡住时按 E，会经过渐黑并在同一卧室假醒；门外切换到第二层地图。第二层出口进入明确的醒来结束页，不再追加假醒；当前出口仍是地面标记占位。已接入猫群观察／正常离开／回访变化与左右门建议的可选灰盒事件，旁白暂用无声字幕；猫使用九只程序化占位模型，不代表已收集玩家偏好。房间之间直接共墙开门，其他边界封闭。尚无怪物、普通死亡流程、声音或 AI 服务，也未完成完整剧情组合与追逐验收。

剧情先检查已有空间：猫房需要可达观察点和群体视线；左右门需要有效入场方向、真实门位及可读距离。条件不足就跳过，不改房型或补造路线。第一层的 seed 12 同时具备这两种场景；seed 4 可检查猫房，seed 6 可检查左右门。连续看见至少六只猫 0.8 秒后，正常穿门离开才改变猫群；回访再次看见才显示对应字幕。左右门提示完整显示后，真正穿过右门才触发选路评论。暂停冻结剧情与转场计时，新局清空剧情状态。切层取消旧字幕，保留全局台词消费与行为预算，并归档第一层经历；猫房实例不跨层继承，第二层暂不再次安排 CAT01。已接入初醒、看见第一层出口、假醒字幕和最终结束文字。第二层目前用于验证流程，威胁与跨层物件呼应尚未实现。

## 验证与构建

```sh
npm test
npm run build
npm run preview
```

构建输出位于 `dist/`，预览地址为 http://127.0.0.1:4191/ 。

- `src/state.js`：独立的游戏状态。
- `src/flow.js`：出口交互、转场、跨层状态和主流程字幕。
- `src/story/`：视锥与遮挡、实际过门、猫房和选路字幕状态。
- `src/collision.js`：平面碰撞与分步移动。
- `src/planning/`：房型、种子布局、碰撞校验、有限重试与保底计划。
- `src/world.js`：将生成计划装配成场景、灯光和门，共用已验证的碰撞体。
- `src/map-preview.js`：纯数据计划的调试平面图。
- `src/main.js`：输入、游戏循环与界面。
- `tests/`：碰撞、状态、确定性、100 个种子通行、错误布局与保底测试。
